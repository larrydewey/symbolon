## What's new

- **Built with [Resid v0.12.0](https://github.com/larrydewey/Resid/releases/tag/v0.12.0).** The agent, relay, witnesses, cosigner and Symbolon Home are rebuilt with the new compiler and runtime. Symbolon's own agent code is unchanged from 0.8.1.
  - **SSH consent answered after 30 seconds now signs.** The agent gives the consent sheet five minutes, but the old runtime ended any socket wait after 30 s. On a phone, a sheet answered later than that (unlocking, reading it, typing the PIN) found the request expired ("This request has expired"), and the SSH client reported that the agent did not sign. The full five minutes now hold.
  - Secret mode starts wiping freed memory at the first code that handles a secret instead of at process start. It stays on for device and native hosts.
- **The app is on Flutter 3.50.1.** Its Material widgets come from `package:material_ui`, which replaces the deprecated `package:flutter/material.dart`. Its Dart packages are up to date.
- **Build tooling is current.** CI uses Java 25 (LTS), Gradle 9.9.2, Android Gradle Plugin 9.5.2, Kotlin 2.4.21, current GitHub Actions and Ubuntu 26.04 runners.

## Updating

Install the APK over 0.8.1 or earlier. It is signed with the same key. The browser extension is unchanged apart from its version number.

## Files

- `symbolon-v0.8.2.apk`: the Android app (arm64 and x86_64).
- `symbolon-extension-v0.8.2.zip`: the browser extension.
- `SHA256SUMS`: checksums of the files above.

## Tests

- `symbolon-resid/tests/run.sh` was run with the agent built against Resid v0.12.0. All 27 unit test files and the services test pass. So do the end-to-end suites: cli (plain and TLS), tpm, home, share, org, store, rotate, breach, fill_lock, browser, ssh, fido and link. `fido_usb` was skipped because no key was plugged in.
- Resid v0.12.0 passed all 19 of its own suites before release.
- The app under Flutter 3.50.1: `flutter analyze` finds no issues, and `flutter test` passes (119 tests).
- A debug APK was built locally with the new Gradle and Android Gradle Plugin. The release APK was not tried on a device.
