## What's new

- **Built with [Resid v0.11.0](https://github.com/larrydewey/Resid/releases/tag/v0.11.0).** Symbolon's own code is unchanged from 0.8.0; the agent, relay, witnesses, cosigner and Symbolon Home are rebuilt with the new compiler and runtime.
  - A large value carried through a loop is no longer copied each time the loop's memory is compacted. Long-running servers that hold big buffers (the relay, the cosigner, Symbolon Home) do less copying and peak lower.
  - `sha256g` copies only the padded tail of a message instead of the whole message, so hashing large items and exports takes less memory.

## Updating

Install the APK over 0.8.0 or earlier; it is signed with the same key. On Linux, replace the binary with this release's. On a Symbolon Home box, restart its services after replacing the binary. The browser extension is unchanged apart from its version number.

## Files

- `symbolon-v0.8.1.apk`: the Android app (arm64 and x86_64).
- `symbolon-v0.8.1-linux-x86_64`, `symbolon-v0.8.1-linux-aarch64`: the agent and servers for Linux.
- `symbolon-extension-v0.8.1.zip`: the browser extension.
- `SHA256SUMS`: checksums of the files above.

## Tests

- `symbolon-resid/tests/run.sh` was run with the agent built against Resid v0.11.0. All 27 unit test files pass, and so do the end-to-end suites: net services, cli (plain and TLS), tpm, home, share, org, store, rotate, breach, fill_lock, browser, ssh, fido and link. `fido_usb` was skipped because no key was plugged in.
- Resid v0.11.0 passed all 19 of its own suites before release.
- The app's code is unchanged from 0.8.0, so the Flutter suite was not run again. The APK was not tried on a device.
