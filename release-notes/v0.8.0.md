## What's new

### The breach check in the app

0.7.0 added a check of your logins against [Pwned Passwords](https://haveibeenpwned.com/Passwords), but only on the command line. The Android and Linux apps now run it too, and show what it found in every place a login appears.

- **More › Breached passwords** runs the check, as does **Check for breached passwords** under the vault list. It asks for your PIN, then lists each breached login with the number of times its password has been seen. Tap a login to open it. A shared folder is checked from its own list.
- As in 0.7.0, your passwords never leave the device. Only the first five hex digits of each password's SHA-1 hash are sent, in a padded request, and the match is made on the device. If the service cannot be reached, or its certificate does not verify, the check fails instead of reporting your logins as clean.
- The app keeps what the last check found on this device: the names of the breached logins and their counts, never a password or a hash. With that it can warn you everywhere:
  - the vault shows a banner and a red **Breached** tag on each of those logins;
  - the login's own page warns at the top;
  - the browser extension's fill window and Android autofill mark the login in red, but still fill it, so you can sign in and change the password.
- Changing the password in Symbolon, or with **Change password at the site…**, clears the warning. Renaming a login keeps it. Deleting or moving a login removes it.
- Protected items are skipped (they cannot be made yet), and the check says how many it skipped.

### Android

- The agent can now look up host names on Android. It needs to for `api.pwnedpasswords.com`, and the app now gives it the network's DNS servers. This adds the `ACCESS_NETWORK_STATE` permission, which Android grants without asking.
- The agent checks the service's certificate against the phone's own trusted roots. The app gathers them into a single file for the agent.

## Updating

Install the APK over 0.7.0 or any 0.6.x. It is signed with the same key as before. The agent is the same as in 0.7.0, so there are no new Linux binaries: use 0.7.0's. The Linux desktop app comes from source as before. The browser extension is unchanged apart from its version number.

## Files

- `symbolon-v0.8.0.apk`: the Android app (arm64 and x86_64).
- `symbolon-extension-v0.8.0.zip`: the browser extension.
- `SHA256SUMS`: checksums of the files above.

## Tests

- The app's Flutter suite passes: 119 tests, with the 43 tour screenshots skipped. New tests cover:
  - running the check from More, and its findings in the result list, on the item page, in the vault banner and as tags;
  - a new password clearing a finding, and a rename keeping it;
  - a login opened from the results asking before a rename replaces another item;
  - the warning in the browser fill window, with the login still filled;
  - reading the agent's report, findings surviving a restart, per folder, and another window's save keeping them;
  - building the root bundle from Android-style certificate files.
- `symbolon-resid/tests/breach_e2e.sh` has a new opt-in live mode (`LIVE=1`), run for this release against the real api.pwnedpasswords.com. It reported both test passwords as breached (52,373,976 and 3,196 times) and the random one as clean, first with the system's roots and then as the Android app runs it: 118 roots gathered from one-certificate files, with DNS servers taken from `RESID_RESOLV_CONF`.
- The release APK builds.
- Not tested: the check in the app on a phone or emulator, and Android autofill showing the warning on a device.
